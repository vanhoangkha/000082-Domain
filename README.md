# Serverless - Setting up SSL for your serverless app

> Custom domains with Amazon Route 53.

A hands-on workshop from the [AWS First Cloud Journey](https://github.com/vanhoangkha/aws-first-cloud-journey) series, available in English and Vietnamese.

**Read the workshop online:** https://vanhoangkha.github.io/000082-Domain/

## Overview

In this workshop in the serverless series, we will set up website application to be more secure in transit by using an SSL certificate. An SSL Certificate allows traffic between a user and a website application hosted on an S3 bucket to be encrypted in transit (in-flight encryption).

## Prerequisites

- An AWS account with permissions to create the resources used in the labs
- Basic familiarity with the AWS Management Console
- [Hugo](https://gohugo.io/installation/) (extended edition) if you want to run the site locally

## Run locally

```bash
git clone https://github.com/vanhoangkha/000082-Domain.git
cd 000082-Domain
hugo server
```

Then open http://localhost:1313 in your browser.

## Repository structure

| Path | Purpose |
